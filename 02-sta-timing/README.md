# ⏱️ Static Timing Analysis

### Naresh Lankalapalli

Tools for analyzing timing on gate-level netlists.

| Tool | Purpose | Script | Storage |
|------|---------|--------|---------|
| **OpenSTA** | Static timing analysis with setup/hold checks | `install_opensta.sh` | ~300 MB |
| **OpenTimer** | High-performance STA with incremental updates | `install_opentimer.sh` | ~200 MB |

## Install all STA tools
```bash
../install.sh --sta
```
