# 🎁 Extra Tools

### CIRCUIT_IQ — circuits to silicon

| Tool | Purpose | Script | Storage |
|------|---------|--------|---------|
| **RISC-V Toolchain** | GCC cross-compiler for RISC-V processors | `install_riscv_toolchain.sh` | ~200 MB |
| **IRSIM** | Switch-level simulator for MOS circuits | `install_irsim.sh` | ~50 MB |

## Install all extras
```bash
../install.sh --extras
```
